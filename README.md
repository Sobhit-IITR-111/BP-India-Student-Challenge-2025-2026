# BP-India-Student-Challenge-2025-2026
Participated in a national level Geoscience Competition organized by bp and EAGE jointly.
This branch contains the report of the work progressed in the Phase-II entitled on "Integrated  Dynamic  Reservoir  Characterization  and  Field  Development  Planning".

Project Description:
1) Synthesized 4D seismic, 24+ years production–injection history and multi-well surveillance to evaluate dynamic reservoir behavior, pressure support patterns, VRR trends and water-cut evolution in a mature waterflooded clastic reservoir.

2) Conducted Arps decline analysis, injector–producer correlation and waterflood diagnostics across 5 producers and 8 injectors to quantify sweep efficiency, identify bypassed pay and map unswept oil zones using 4D seismic response.

3) Engineered uncertainty-driven FDP and ENPV workflows integrating CAPEX/OPEX, P90–P50–P10 volumetrics, injection–production risk characterization and reservoir surveillance strategies for redevelopment planning.
